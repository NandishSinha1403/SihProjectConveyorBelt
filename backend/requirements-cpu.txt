# Server install. The default PyPI torch wheel bundles CUDA and is several
# gigabytes; a cloud box with no GPU pays that entirely for nothing. This pulls
# the CPU-only build instead, which is roughly a tenth of the size and is the
# difference between a build that fits a small instance and one that does not.
--extra-index-url https://download.pytorch.org/whl/cpu

-r requirements.txt
